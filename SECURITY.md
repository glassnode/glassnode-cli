# Security policy

## Reporting a vulnerability

Please do not report security issues through public GitHub issues.

Use GitHub's private vulnerability reporting instead: open the
[Security tab](https://github.com/glassnode/glassnode-cli/security/advisories/new)
of this repository and choose **Report a vulnerability**. The report reaches the
maintainers listed in [CODEOWNERS](CODEOWNERS) only.

If you can't use GitHub, email security@glassnode.com.

Include what you can of the following:

- the affected version (`gn --version`) or commit,
- a description of the issue and its impact,
- steps that reproduce it.

You will get an acknowledgement within five working days. We will keep you
informed about the fix and credit you in the release notes unless you prefer
otherwise. Glassnode has no bug bounty program.

## Supported versions

Security fixes are released for the latest version only. Update to the most
recent release before reporting.

## Scope

This repository contains the `gn` command-line interface, its install scripts
and its release artifacts. Issues in the Glassnode API itself or in other
Glassnode products should be reported to Glassnode through the contact options
at [glassnode.com](https://glassnode.com).
